# v0.2.0

**Release Date:** 2026-07-19

Adds an OmniAvatar render adapter so bitHuman video generation can be used behind the provider-agnostic [OmniAvatar](https://github.com/plexusone/omniavatar) interfaces.

## Highlights

- OmniAvatar render adapter for bitHuman video generation

## Added

- `omniavatar` subpackage: an OmniAvatar render adapter implementing the omniavatar-core render interfaces (`render.Provider`, `render.AudioUploader` via the bitHuman file API) on top of this SDK. Depends only on `omniavatar-core`; provider-specific knowledge stays in this repo. The real-time (live) adapter, which requires LiveKit, lives in the batteries-included [`omniavatar`](https://github.com/plexusone/omniavatar) package.

## Dependencies

- Require `omniavatar-core` v0.3.0 (interfaces + render helpers) for the render adapter
- Update indirect dependencies
